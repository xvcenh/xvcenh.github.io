📖 玩法说明

🐟 核心规则：吞食比自己小的鱼成长，躲开比自己大的鱼。被咬会损失体型，体型过小会被吞食。

🃏 Rogue 进化：吞食攒进化点，升级时三选一。凑齐同流派卡牌激活羁绊 —— 速度流 / 剧毒流 / 巨兽流 / 灵巧流 / 诅咒流。

🌍 场景机制：珊瑚礁 → 荧光水母（电网！）→ 沉船暗流 → 冰海浮冰白雾 → 火山喷发 → 深渊黑暗。

🤝 合作：队友倒下后靠近按 F / 右Shift 复活（消耗自身体型）。BOSS 需要两人同时咬住弱点。

⚔️ 竞争：互相抢食抢进化点；当场上鱼被吃完，进入终局撕咬 —— 互相撕咬，体型小的被吞掉。

🎮 操作：P1 = WASD + 空格冲刺；P2 = 方向键 + 回车冲刺；支持手柄。
