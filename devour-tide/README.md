# 吞噬之潮 · Devour Tide

深海题材的**下潜生存 Roguelike**：你是逃逸的实验鱼，被人类装备从头顶一路追压，
必须不断向更深处下潜 —— 深度就是难度，进度就是你游下去的米数。

- **连续下潜世界**：12 段 × 2600px 的竖直深海柱，6 片海域随深度渐变过渡，全程无转场加载
- **追赶者**：渔网/声呐/钻探平台等人类装备从画面顶部缓慢压下来（规划中的叙事化形态），
  停下就会被追上；右上角小地图实时显示你与追赶者的相对位置
- **器官构筑**：吃什么长什么，每局 3 个器官槽位；12 张强化卡在段界结算
- **6 台 Boss**：固定深度拦路；战胜终局机甲后解锁无尽下潜（规划中）
- **双人合作**：同屏两人，倒下成灵魂后队友靠近救起；手机上自动禁用

## 🚀 运行

**方式一**：直接访问线上 `https://xvcenh.github.io/devour-tide/`

**方式二**：双击 `index.html`（构建产物，即开即玩）

**开发模式**（改代码用）：

```bash
cd source
npm install        # 首次
npm run dev        # Vite 开发服务器，改 src/ 即时热更
npm run build      # 构建到上级目录（index.html + assets/）
```

> `index.html` 与 `assets/` 是**构建产物**，不要手改；
> 源码在 `source/src/`：`utils.js`（纯工具）→ `config.js`（静态数据）→ `audio.js`（合成音效）→ `game.js`（其余全部）。
> 后续会把渲染 / 图鉴 / HUD 从 game.js 继续拆出。
