# 吞噬之潮 · Devour Tide（豪华版）

深海题材的 **卡牌构筑 Roguelike**：吞食成长、16 段分支航路、200+ 热梗道具、羁绊联动、
可吞噬的 Boss 特性，外加双人同屏合作与对抗。

> **单文件 · 零依赖**：`index.html` 176KB，全程序化渲染，无任何图片 / 音频 / CDN / 字体外链。
> 双击即玩，也能直接丢到任何静态托管上。

## 🚀 运行

**方式一**：双击 `index.html`（推荐 Chrome / Edge）

**方式二**：起个本地服务

```bash
python3 -m http.server 8000   # 浏览器打开 http://localhost:8000
```

## 🕹 游戏模式

- **🎣 单人启程**：16 段航路，通关即成为深海霸主
- **🤝 双人合作（同屏）**：体型被咬空会倒下成灵魂，队友靠近即可救起
- **⚔️ 双人对抗（同屏）**：抢食争分，冲刺撞晕对手并偷取分数

## 🗺 航路地图

每局生成 16 行分叉路线，节点类型：

| 节点 | 说明 |
| --- | --- |
| ⚔️ 战斗 | 吞食成长、完成目标即可晋级 |
| 💀 小Boss | 精英战，击败可吞噬一条特性 |
| 👑 大Boss | 固定在第 5 / 10 / 16 段 |
| ❓ 奇遇 | 三选一，高风险高回报 |
| 🛒 商人 | 花 💎 珍珠买卡牌与治疗 |
| 🎁 宝藏 | 免费三选一 |
| 🌙 休息 | 体型大幅回复 |

## 🃏 构筑

**36 张卡牌 + 200 件道具 = 236 种奖励**，按普通 / 稀有 / 史诗 / 传说 / 诅咒五档权重随机。

200 件道具由「40 个热梗名 × 5 种后缀 × 32 类效果原型」程序化生成
（打工人之鳞、显眼包尾迹、泼天富贵光环…），**每件都会给鱼叠加一个外观装饰**
——王冠、墨镜、披风、大金链子、火焰角，共 20 种。

**三层羁绊**：
- 同 tag 协同：成长 / 速度 / 防御 / 连击 / 分数 / 冲刺 / 狩猎
- 同 family 2 件、4 件加成
- 双道具联动：寒冰+灼热=蒸汽爆发、冲刺双件=流体力学、暴击+连击倍率=暴击风暴…

## 👑 Boss 与吞噬

4 个 Boss（深渊巨鲨 / 冰霜古鲸 / 幽灵魔魟 / 熔岩巨兽），各有速度、体型、血量倍率与独立攻击形态。
击败后可**吞噬其特性永久为己所用**：巨鲨之怒、古鲸寒息、魔魟之影、熔岩之心，以及小 Boss 掉落的 4 种迷你特性。

## 🌊 每局都不同

- **5 类轮换目标**：吞食 / 累计得分 / 坚持生存 / 猎杀精英 / 达成连击
- **7 种环境词缀**：富饶、狂潮、洋流、巨物时代、祝福之光、永夜、星雨（42% 概率叠 2 个）
- **7 种随机事件**：金潮、鱼群暴动、漂流宝藏、治愈之潮、漩涡、丰饶之海、猎杀时刻
- **阶段评分**：S / A / B / C

## 🐠 养成与图鉴

8 种初始鱼（被动各异）、6 皮肤、4 鱼鳍、4 尾迹，靠最高分 / 击败 Boss 数 / 到达阶段解锁。
📖 深海图鉴 6 个 tab（鱼 / 道具 / Boss / 词缀 / 事件 / 节点），内容全由游戏数据动态生成。

## 🎨 场景

珊瑚浅海 → 幽暗海沟 → 冰封海域 → 火山热泉 → 远古遗迹（按航路段数循环，各自独立装饰与雾效）

## ⚙️ 技术要点

- 11 种鱼形态各自独立的绘制函数，外加「三层丝带鱼鳍」与「脊椎弯曲柔性鱼」两套画法
- 镜头跟随 + 随体型缩放，暗角与扫描线后处理
- Web Audio 全合成音效，无音频文件
- `localStorage` 存档：最高分、最远阶段、Boss 击杀数、解锁列表
- 设置项可调视野大小与震动强度

## 📦 打包成 exe

单文件性质决定了分发极简单：直接把 `index.html` 发出去让对方双击即可，无需安装任何东西。

需要真 exe 时可用 Electron（约 180MB）或 Tauri（约 8MB）包一层外壳。
