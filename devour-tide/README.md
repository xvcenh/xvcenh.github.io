# 吞噬之潮 · Devour Tide

逃出实验室的 T-07 正被追踪。玩家可以选八种鱼中的一条，在珊瑚浅海、幽暗海沟、冰封海域、火山热泉、远古遗迹和深渊之间下潜。

- 六片海域共有十二段，深度条显示守卫、海底目标和追赶者的位置。
- 冲刺劈开鱼阵，或沿鱼群的尾流隐藏。渔网、回声环和黑匣需要不同的操作。
- 吞食猎物可以进化器官。段末提供强化卡，蓝鲸和人类设施的选择影响结局。
- 桌面支持同屏双人和救援。手机使用摇杆与动作键，可在暂停菜单选择赛璐璐、蓝墨漫画或夕照剧场滤镜。

## 🚀 运行

直接从[博客游戏入口](https://xvcenh.github.io/devour-tide/anime/)开始游玩。入口也提供安卓安装包和 Windows x64 压缩包。

离线网页版请打开打包后的单文件 HTML。Phaser 引擎、游戏逻辑和原画都嵌在文件里。开发者可查看[构建说明](BUILD.md)和[动漫素材索引](source/art/README.md)。

**开发模式**（改代码用）：

```bash
cd source
npm install        # 首次
npm run dev        # Vite 开发服务器，改 src/ 即时热更
npm run build      # 构建到上级目录（index.html + assets/）
```

> `index.html` 与 `assets/` 是**构建产物**，不要手改；
> 源码在 `source/src/`：`utils.js`（纯工具）→ `config.js`（静态数据）→ `audio.js`（合成音效）→ `game.js`（其余全部）。
> 后续会把渲染 / 图鉴 / HUD 从 game.js 继续拆出。

## 🎮 操作

| 动作 | P1 | P2 |
| --- | --- | --- |
| 移动 | W A S D | ↑ ↓ ← → |
| 冲刺 | Shift / 空格 | Enter |
| 啃咬 | J | / |
| 技能 | K | ； |
| 释放封印 | Q | M |
| 图鉴 / 暂停 | Tab / Esc | 同左 |
| 视野缩放 | 滚轮（+/- 复位 0） | — |

移动端：触屏自动进入手机模式（左下浮动摇杆 + 右下四个键），`?mobile=1/0` 可强制开关。
调试钩子：`?debug=1` 暴露 `window.__DT`（内部状态 + update），供自动化测试。
