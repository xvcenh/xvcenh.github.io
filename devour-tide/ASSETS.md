# 吞噬之潮 ·「逃离实验室」视觉素材规格清单

> 本文件是给图像生成工具/画师的**投喂规格**。按此生成即可直接拖入项目，
> 代码端有兜底：任何素材缺失时游戏继续用程序化绘制运行，可分期交付。
> 交付路径：`devour-tide/assets/img/<组名>/<文件名>.png`（大图附 `@2x` 版本）

## 0. 全局规范（必读）

| 项 | 要求 |
|---|---|
| 运行环境 | Canvas 2D 游戏精灵，背景为极深海水（`#051f38` → `#010206`） |
| 格式 | PNG 透明底；宽幅大图可选 WebP（质量 90） |
| 朝向 | 游动类角色一律**朝右**（游戏内自动水平翻转）；装备机械按表中说明 |
| 锚点 | 角色 = 图像中心；宽幅横条 = 底边中心 |
| 尺寸 | 按 1x 交付并另附 @2x（retina），文件名如 `net@2x.png` |
| 风格 | 现代扁平矢量插画 + 轻霓虹发光边缘；**剪影可读性第一**（缩到 64px 仍能认出是什么）；同组统一光源：上方微弱顶光 + 自发光元素 |
| 禁止 | 图内出现任何文字/字母/数字/水印、不透明背景、照片写实风 |
| 附加说明 | 游戏内会做旋转/缩放/透明度动画，单帧静态图即可；序列帧仅 P2 条目需要 |

## 代码接入约定（给开发侧的备忘）

- 新增 `src/assets.js` 加载器：`Promise` 预载全表 + **逐张失败回退**（任何一张加载失败/缺失 → 该元素继续走程序化绘制，游戏不报错不中断）。
- 资源放入 `devour-tide/assets/img/`，Vite 经 `public/` 目录拷贝进构建产物。
- 精灵图在游戏中大量旋转/翻转，生成时**不要**把高光方向画得太死（顶光可以，侧向强光影不行）。
- 敌鱼/玩家鱼目前代码里每个物种有 `c1/c2` 双色（体色/发光色），生成时以此为准，接入后这两个字段仅作为调色兜底与光效染色。
