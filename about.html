为什么写工程手记

我主要关注软件架构、DevOps 运维和数据库管理。一个难复现的错误，一次终于跑通的部署，过几个月都可能变得陌生。我把环境、思路和解法一起留下，方便自己回来查，也让遇到同样问题的人有个起点。

平时在做什么

用 Python 和 JavaScript 写工具，用 Docker、Nginx 和数据库搭服务。工作之余，我会把技术问题做成小实验，让一组参数、一段动画或一个终端窗口把原理讲清楚。
